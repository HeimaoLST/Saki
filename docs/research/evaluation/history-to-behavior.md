# History to behavior：评测证据与方法

核对日期：2026-10-05。状态：论文与官方评测报告审阅；未本地复现。

## 我们需要测五件不同的事

| 层次 | 问题 | 单凭它不能证明什么 |
| --- | --- | --- |
| 记忆 | 能否找回经历及正确来源？ | 找回后会影响行动 |
| 历史影响 | 改变持久状态后，行动是否改变？ | 改变更好，或存在独立 Belief 机制 |
| 学习质量 | 未见同类任务更好，边界任务不被误导？ | 所有价值偏好应朝同一方向变化 |
| 可修正性 | 相反证据能否改变条件判断？ | 长期人格发展或意识 |
| 长期使用收益 | 用户的重复指导、纠正和返工是否减少，整体质量与成本是否可接受？ | 单次满意度能覆盖所有可靠性问题 |

一句“我记得上次失败，所以这次谨慎”可以作为解释材料。它不能替代工具行动与状态干预，因为模型也可能在事后编造合理理由。

产品目标是让会成长的 agent 更好用。任务成功率与历史因果作用属于机制和质量证据，仍需观察用户为了完成任务付出了多少额外工作。评测可记录重复纠正、补充背景、人工救援、返工以及不必要的确认；有助于明确需求的合理澄清不应一概计为失败。

满意度和协作偏好可以补充客观结果，但不作为唯一判据。长期协作收益需通过连续使用检验；第一轮受控实验只能给出有限任务范围内的证据。

## MemoryArena：评价跨会话行动链

MemoryArena 构造互相依赖的跨会话任务，覆盖购物、规划、渐进搜索和形式推理，早期行动与反馈影响后续任务。与只问历史事实相比，这更接近 SAKI 的目标。[论文 v2](https://arxiv.org/abs/2602.16313v2)、[ICML 2026 页面](https://proceedings.mlr.press/v306/he26am.html)。

版本限制：v2 于 2026-09-17 更新，但正文与表格的 GPT-5-mini／GPT-5.1-mini 命名存在不一致，还包括 Gemini 3 Flash 和 Claude Sonnet 4.5／附录 4.6；本次未发现 GPT-6 结果。采用其任务结构，不据此预测最新模型排名。

## MemDelta：强基线与成本必须受控

MemDelta 在 LongMemEval-S 上逐项改变 retrieval、embedding、回答模型和写入路径，展示记忆方案排名会随这些变量变化。其完整矩阵使用 GPT-4o-mini，其他比较包括 Claude Sonnet 和 Gemini 2.5 Flash；Mem0 的部分对比只覆盖 88 个问题，embedding 也不是完全相同。[论文 v1，2026-06-29](https://arxiv.org/html/2606.29914v1)。

因此这里只采用控制变量和写入成本统计的方法，不把其结果解释成“最新模型不需要 Belief”，也不把记忆问答等同于行动学习。SAKI 的 Belief 提案必须与同模型、同工具、同检索器的原始经历检索比较；训练／反思成本与在线回答成本分开记录。

## PASTBench 与 STALE：持久性也需要更细的区分

PASTBench 比较跨任务保留状态与不保留状态，并使用新上下文检查持续适应。其 trace 与改进一致，不等于某条反思已经得到因果证明。实验包括 GPT-5.4、Claude 4.6、DeepSeek V4 Pro 等，本次未发现 GPT-6 实验。[PASTBench，2026-08](https://arxiv.org/abs/2608.04003)。

STALE 区分状态更新与隐式策略适应。后者评价推荐输出，不能当成实际工具行动的测量；其框架比较使用较旧的 GPT-4o-mini backbone，部分单模型实验包括 GPT-5.4 系列。数据生成模型与被测模型也须区分。[STALE，2026-05](https://arxiv.org/abs/2605.06527)。

**设计推论**：借鉴新会话、状态开关和策略适应任务；增加具体状态移植、消融与行动记录，避免仅比较两段回复。

## 项目方生产评测的价值与限制

Letta 的 2026-07 ContextBench V2 报告从生产 trace 构造场景，分别关注检索遵循与记忆泛化／整理；使用多种 2026 模型，但属于项目方发布的私有评测。它提供问题分类和实践线索，不等于公开独立复现。[官方报告](https://www.letta.com/blog/evaluating-memory-in-production-agents/)。

SkillOpt 的 2026-07 报告研究反思更新与 gate，包含 GPT-5.5／GPT-5.4 mini、nano 和 Qwen3.5-4B。部分比较同时改变多项控制，逐次原始结果未完整公开；不能把分差全部归因于单一 gate，也不能把 oracle 选择当成部署时可用的选择策略。[官方报告](https://microsoft.github.io/SkillOpt/blog/gating-reflection-safe-updates/)。

## 怎样回应“论文模型太旧”

论文发布日期、源码维护日期、实验模型版本是三个不同日期。最新论文可能仍使用旧模型，维护中的项目也可能只有旧评测。来源索引分别记录它们，不用“最新”笼统代替。

已有研究可以帮助设计可复核的实验，但不能代替在目标模型上重新测试。当前资料没有直接证明 SAKI 在 GPT-6 或当前 DeepSeek 模型上能稳定完成经历到判断到行为的闭环；也未宣称穷尽所有最新工作。

## 对第一轮实验的建议

使用可核验结果的受控任务和新会话，测量第一步工具行动、任务结果、重复错误、用户纠正与人工救援、无关改动、工具次数、token 与 latency。增加原始经历检索、判断状态移植和来源屏蔽对照，并测试同类迁移、边界反例和相反证据。

完整协议见 [History dependence](../../experiments/history-dependence.md)。这套实验检验特定持久状态对行动的作用及有限任务范围内的使用收益；之后再扩大到长期协作、关系历史和主动性。
